# Browser reference snapshot

This copy of the [Fall of Duty browser source](https://github.com/AJ7-III/Fall-of-Duty/tree/ecfb87d80d1002a086afaf6f657f4ad2c3f23467) supplies the asset exporter, game-data generator, and optional replay capture. The import includes the Lite-compatible viewmodel adjustments from the original working tree. Its HTML entry point uses a relative path for capture from this directory.

The firmware and desktop game use the native C++ engine. The captured reference journals and input traces are in [reference/fixtures](../fixtures). The original browser model is supplied separately for optional capture, as described in the [asset pipeline](../../ASSET_PIPELINE.md#capture-a-new-browser-baseline).
